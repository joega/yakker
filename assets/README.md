# Station artwork

`sports-hub.png` is the 98.5 The Sports Hub station logo,
downloaded from the station's website on 2026-10-17 at a CDN width of 192 pixels:

https://985thesportshub.com/uploads/2017/12/985_with-ring_white-1.png?format=png&width=192&optimize=high

Original reference:
https://985thesportshub.com/uploads/2017/12/985_with-ring_white-1.png

It is used for station identification in the bar and popup. The station logo and
associated marks belong to their respective owners and are not covered by this
repository's MIT code license. This plugin is unaffiliated with the broadcasters.
The file is bundled locally; rendering it makes no network requests.
